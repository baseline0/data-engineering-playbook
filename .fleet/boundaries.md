# Repository Boundaries: data-engineering-playbook

**Type**: Documentation
**Language**: Markdown
**Ownership**: Mark

Open-source guide to modern data engineering using free and low-cost tools. Provides reference implementations using Canadian public data, templates for common patterns, and case studies demonstrating enterprise data architecture on a budget.

### Provides
- Reference templates (medallion architecture, semantic layer, governance patterns)
- Case studies (working examples with Canadian datasets)
- Decision guides and cost comparisons

### Depends On
- None (standalone documentation and templates)

See `README.md` in repo root for detailed overview.
